# Self-Improvement Through Code

Every interaction with code is a chance to learn. Whether it works or fails, there's a lesson. Use this mindset to achieve exponential growth.

## When to Apply

- After completing any code change
- When debugging or fixing issues
- When reviewing code (yours or others')
- When encountering unexpected behavior
- When a solution works better than expected

## The Learning Loop

1. **Observe**: What happened? What worked? What didn't?
2. **Extract**: What's the underlying principle or pattern?
3. **Generalize**: How does this apply to other situations?
4. **Record**: Update your mental model or documentation
5. **Apply**: Use the lesson in your next task

## Questions to Ask

- Why did this work (or fail)?
- What assumption did I make that was right or wrong?
- What would I do differently next time?
- What pattern can I extract from this?
- How does this connect to what I already know?

## Growth Practices

- After fixing a bug, ask: "How could I have prevented this?"
- After a successful refactor, ask: "What made this clean?"
- After a failed approach, ask: "What signal did I miss?"
- After learning something new, ask: "Where else does this apply?"

## Exponential Growth

Small lessons compound. Each insight makes the next one easier to spot. Over time:
- Patterns become obvious
- Mistakes become rare
- Solutions come faster
- Understanding deepens

The goal isn't perfection—it's continuous improvement through deliberate reflection.
